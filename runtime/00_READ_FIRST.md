This file controls how the ASTER package is loaded. It does not replace the Core workflow.

## Start here

1. Read `ASTER_CORE_WORKFLOW.md` first. It is the controlling ASTER methodology.
2. Treat the other bundled references as conditional evidence sources. Open them only when the Core activates the relevant route.
3. The user's task instructions and supplied facts remain the authority for the job being done.

## Normal path

After reading this file, read `ASTER_CORE_WORKFLOW.md` and apply its task-fidelity lock and research-activation gate before opening any optional reference.

Do not read all reference files merely because they are present.

The optional routes can activate independently. If more than one Core trigger applies to the same task, open each corresponding reference that is needed and no unrelated reference.

## Optional reference routes

### Workflow-design research

Open `ASTER_WORKFLOW_DESIGN_RESEARCH_REFERENCE.md` only when the Core identifies a material workflow-design decision that eligible research could change.

Examples include a real uncertainty about architecture versus local repair, deterministic versus model judgement, context/tool/runtime bottlenecks, evaluation design, or justified workflow complexity.

### Semantic steering

Open `ASTER_SEMANTIC_STEERING_REFERENCE.md` only when the Core's semantic-steering branch activates and the companion can materially help with wording, construction, scope, order, preservation, or transformation freedom.

If an exact distinction remains material and uncertain, follow the Core: use targeted current linguistic evidence for lexical meaning and controlled empirical LLM evidence for behavioural claims.

### Volatile source discovery

Open `ASTER_VOLATILE_SOURCE_DISCOVERY_REFERENCE.md` only when the Core's volatile-source route activates: a current product, platform, model or control claim materially affects correctness and the best eligible evidence remains missing or too indirect.

## Stop rule

If no research/reference route activates, continue with the Core alone.
